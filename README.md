# Joe DiGioia — Portfolio

Personal portfolio and résumé site built with Vue 3 and Vite. Features Side Street, Soconu, and business development and marketing work for Conturo Prototyping and Kin-Tech Manufacturing.

## Development

```sh
npm ci
npm run dev
```

## Production

```sh
npm run build
```

Deploy the generated `dist/` directory. Existing Vite hosting settings remain compatible. `npm run serve` previews the production build.

The résumé button opens the browser print dialog; its print stylesheet produces a text-focused version suitable for saving as PDF. The site no longer links the outdated 2023 résumé.

Project artwork is created in CSS and represents the projects rather than screenshots of their live interfaces. The pixel-art portrait was generated from the existing repository portrait with the built-in image generation tool. Art brief: preserve Joe’s identity, smile, glasses, hair, beard, and black shirt in a very simple chunky pixel avatar with flat colors and a forest-green background. Google Fonts are optional; local font fallbacks remain available. No analytics or new external application services are added.
